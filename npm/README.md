# 3d-ascii

Procedurally generated cities, forests, islands and a dragon, ray traced into ASCII art in your terminal.

```bash
npx 3d-ascii              # the city
npx 3d-ascii ocean --seed 42
npx 3d-ascii --help       # every option and key
```

`1` orbits, `2` rides the dragon and `3` the car. `4` drops boxes: a click drops one where it lands, `G` turns their gravity on and off and `X` clears them. WASD or the arrows move, the mouse drags and zooms, a click names what is under it, `Tab` switches environment, `N` makes a new world and `Esc` quits. Needs Node 20 or newer and looks best in a terminal with 24-bit color.

Source and the browser version: https://github.com/sebbejohansson/3dmodel-rendering-techdemo
